# Hotel Management System 🏨

A hotel management system developed using C++ for managing hotel operations such as room booking, customer management, and reservation handling.

---

## 🚀 Features

- Customer registration
- Room booking management
- Hotel record management
- Reservation handling
- Console-based interface

## 🛠 Technologies Used

- C++
- Object-Oriented Programming (OOP)
